---
title: "Quickstart"
description: "Run Relay and send your first request in about two minutes"
---

This runs the standalone image: Relay and its own Postgres in one container, with the catalog seeded on first boot.

<Steps>
  <Step title="Start the relay">
    ```bash
    docker run -p 8080:8080 -p 8081:8081 \
      -v relay-data:/var/lib/postgresql/data \
      wyolet/relay:standalone
    ```

    The volume keeps your data, the generated credentials and the master key across container restarts. The image is built for `linux/amd64`.

    <Info>Admin UI and control API on **:8081**, OpenAI- and Anthropic-compatible inference API on **:8080**.</Info>

    To run the lean image with separate Postgres and Valkey containers instead, use the [Compose stack](/deploy/docker#compose-stack).
  </Step>

  <Step title="Sign in and run the setup wizard">
    On first boot the container prints a generated password for the user `admin`, and an admin token, to its log:

    ```bash
    docker logs <container>
    ```

    Open [localhost:8081](http://localhost:8081), sign in as `admin` with that password, and follow the setup wizard to add a provider's API key and create a relay key.

    <Warning>The relay key is shown **once**, when it is created. Copy it then; only its hash is stored.</Warning>
  </Step>

  <Step title="Make a request">
    <CodeGroup>
    ```bash OpenAI shape
    curl http://localhost:8080/openai/v1/chat/completions \
      -H "Authorization: Bearer <your-relay-key>" \
      -H "Content-Type: application/json" \
      -d '{"model":"gpt-4o","messages":[{"role":"user","content":"hello"}]}'
    ```

    ```bash Anthropic shape
    curl http://localhost:8080/anthropic/v1/messages \
      -H "Authorization: Bearer <your-relay-key>" \
      -H "Content-Type: application/json" \
      -d '{"model":"claude-sonnet-4-6","max_tokens":256,"messages":[{"role":"user","content":"hello"}]}'
    ```
    </CodeGroup>

    Use a model from a provider you added a key for. To see what your relay key can reach:

    ```bash
    curl http://localhost:8080/v1/models -H "Authorization: Bearer <your-relay-key>"
    ```
  </Step>
</Steps>
