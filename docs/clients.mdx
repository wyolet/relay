---
title: "OpenAI and Anthropic SDKs"
description: "Point the official OpenAI and Anthropic client libraries at Relay"
---

Relay accepts the OpenAI and Anthropic wire shapes, so the official SDKs work against it unchanged: set the SDK's base URL to Relay and use your **relay key** (or an inference token) as the API key. Relay reads the credential whether the SDK sends it as a bearer token or as an `x-api-key` header.

| SDK | Base URL | Endpoints it calls |
| --- | --- | --- |
| OpenAI | `http://localhost:8080/openai/v1` | `/openai/v1/chat/completions`, `/openai/v1/responses`, `/openai/v1/embeddings`, `/openai/v1/models` |
| Anthropic | `http://localhost:8080/anthropic` | `/anthropic/v1/messages` |

The model you name does not have to belong to the SDK's vendor. Relay routes it through your policy and translates between shapes, so the OpenAI SDK can call a Claude model and the Anthropic SDK an OpenAI one. Embeddings are the exception: they are forwarded unchanged and need a model with an `adapter: openai` binding.

<Info>
Swap `http://localhost:8080` for your relay's public URL in production. SDK traffic goes to the inference port (`8080` by default), not the control port.
</Info>

For coding agents, use their dedicated base URLs instead: [Claude Code](/claude-code), [Codex CLI](/codex), [OpenCode](/opencode). For Go, the [Go SDK](/go-sdk) speaks Relay's canonical shape.

## OpenAI shape

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/openai/v1",
    api_key="<your-relay-key>",
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "hello"}],
)
print(resp.choices[0].message.content)
```

```javascript Node
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://localhost:8080/openai/v1",
  apiKey: "<your-relay-key>",
});

const resp = await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "hello" }],
});
console.log(resp.choices[0].message.content);
```

```bash cURL
curl http://localhost:8080/openai/v1/chat/completions \
  -H "Authorization: Bearer <your-relay-key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o","messages":[{"role":"user","content":"hello"}]}'
```

</CodeGroup>

The same client reaches the Responses API and embeddings:

```python Python
resp = client.responses.create(model="gpt-4o", input="hello")
print(resp.output_text)

emb = client.embeddings.create(model="<embedding-model>", input="hello")
```

## Anthropic shape

<CodeGroup>

```python Python
from anthropic import Anthropic

client = Anthropic(
    base_url="http://localhost:8080/anthropic",
    api_key="<your-relay-key>",
)

msg = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=256,
    messages=[{"role": "user", "content": "hello"}],
)
print(msg.content[0].text)
```

```javascript Node
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "http://localhost:8080/anthropic",
  apiKey: "<your-relay-key>",
});

const msg = await client.messages.create({
  model: "claude-sonnet-4-6",
  max_tokens: 256,
  messages: [{ role: "user", content: "hello" }],
});
console.log(msg.content[0].text);
```

```bash cURL
curl http://localhost:8080/anthropic/v1/messages \
  -H "Authorization: Bearer <your-relay-key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-sonnet-4-6","max_tokens":256,"messages":[{"role":"user","content":"hello"}]}'
```

</CodeGroup>

## Streaming

Both SDKs stream as usual. When the upstream speaks the same shape, Relay passes the event stream through byte for byte; otherwise it translates each event.

<CodeGroup>

```python OpenAI · Python
stream = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "hello"}],
    stream=True,
)
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
```

```python Anthropic · Python
with client.messages.stream(
    model="claude-sonnet-4-6",
    max_tokens=256,
    messages=[{"role": "user", "content": "hello"}],
) as stream:
    for text in stream.text_stream:
        print(text, end="")
```

</CodeGroup>

## Relay headers from an SDK

Both SDKs let you add headers per client, which is how you send Relay's own request headers, such as usage tags or a host pin. See [Headers](/reference/headers).

<CodeGroup>

```python OpenAI · Python
client = OpenAI(
    base_url="http://localhost:8080/openai/v1",
    api_key="<your-relay-key>",
    default_headers={"X-WR-Request-Tags": '{"job":"nightly-summaries"}'},
)
```

```javascript Anthropic · Node
const client = new Anthropic({
  baseURL: "http://localhost:8080/anthropic",
  apiKey: "<your-relay-key>",
  defaultHeaders: { "X-WR-Request-Tags": '{"job":"nightly-summaries"}' },
});
```

</CodeGroup>

## Which models can I call?

The `model` you pass must be granted by the policy that governs your relay key and have an enabled host binding. List what your key can reach:

```bash
curl http://localhost:8080/v1/models \
  -H "Authorization: Bearer <your-relay-key>"
```

`GET /openai/v1/models`, which the OpenAI SDK's `client.models.list()` calls, returns the same list limited to models with an enabled `adapter: openai` binding.

See [Troubleshooting](/troubleshooting) if a model returns `403` or `404`, and [Errors](/reference/inference-api#errors) for every error code.
